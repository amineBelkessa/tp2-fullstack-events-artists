# 🚀 Fullstack Events & Artists Project

This project is a **fullstack application** for managing **events and artists**, built with a backend API and a frontend client, and dockerized for easy setup.

---

## 📦 Prerequisites

Make sure you have the following installed:

- Git
- Docker
- Docker Compose

Check installation:
```bash
git --version
docker --version
docker compose version
```
## 📥 Clone the repository

```bash
git clone git@github.com:amineBelkessa/tp2-fullstack-events-artists.git
cd tp2-fullstack-events-artists
```

## ▶️ Start the application
```bash
docker compose up -d --build

```

## ⏹ Stop the application
```bash
docker compose down -v

```
